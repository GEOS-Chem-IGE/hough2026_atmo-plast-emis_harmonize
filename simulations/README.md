Modeled atmospheric microplastics
=================================

This directory exists to hold the raw outputs of the atmospheric microplastic cycling simulations.

You can download the archived simulation outputs from https://doi.org/10.5281/zenodo.22925451.


Contents
--------

### [alt/](alt/)

Raw outputs of the *alternate* simulation using the configuration described in Fu et al. (2023).

### [main/](main/)

Raw outputs of the *main* simulation using a power law particle size distribution for atmospheric microplastic emissions.
